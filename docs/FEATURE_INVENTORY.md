# Features

Implemented: persistent local login, separate Lost/Found boards, category/text/status filters, camera/gallery report photos, private identifying details, date/location tagging, duplicate suggestions, report sharing and owner deletion, private recipient-specific messaging, in-app unread alerts, proof sharing, on-device OCR/image-label comparison, private questions, separate ownership confirmations and physical-handover confirmations, report history, scan-to-report drafts, GPS accuracy and map pins.

Optional configured services: Firebase cross-device accounts/reports/photos/messages and Google Maps tiles. See [setup](../SETUP.md) and [limitations](KNOWN_LIMITATIONS.md).
