# Features

Implemented: persistent local login, 100 searchable editable college suggestions, separate Lost/Found boards, category/text/status filters, camera/gallery report photos, private identifying details, date/location tagging, duplicate suggestions, report sharing and owner deletion, private recipient-specific messaging, in-app unread alerts and navigation badges, permission-controlled private Android notifications with exact conversation routing, photo and account toasts, narrow-screen typography, tablet navigation rail and bounded reading panes, proof sharing, on-device OCR/image-label comparison, private questions, separate ownership confirmations and physical-handover confirmations, report history, scan-to-report drafts, GPS accuracy and map pins, a larger styled map viewport, gesture-aware recentering, private saved walking trails with distance/pause/resume/clear controls, and draggable item cards with external walking directions.

Optional configured services: Google OAuth through Credential Manager/Firebase, Firebase cross-device accounts/reports/photos/messages and Google Maps tiles. First-time Google users complete a college profile before entering the dashboard. These services need your configuration; live verification is pending. See [setup](../SETUP.md) and [limitations](KNOWN_LIMITATIONS.md).
