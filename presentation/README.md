# FindIt college presentation

Open the PowerPoint in this folder and enable **Presenter View** to see speaking notes for every slide. Allow roughly 8–10 minutes for the slides, plus time for the app demonstration and questions.

The presentation covers the campus problem, both report workflows, on-device AI, private messaging, shared meeting locations, profile controls, Room and Firebase, and the demonstration sequence.

For the live demonstration on slide 14, use two accounts with the same college and the latest APK. Use a clear label photo for OCR. The screenshots use demonstration accounts and reports. Slide 13 distinguishes completed checks from the remaining physical-device and release checks.
